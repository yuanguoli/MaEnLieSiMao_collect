# 马克思主义经典著作与党的历史文献 PDF 典藏

本项目致力于整理和保存高质量的马克思主义经典著作及中国共产党历史文献电子版本，为文献阅读、全文检索、学术研究和资料查阅提供便利。

本仓库目前收录的主要资源包括：

- **《列宁专题选集》**
- **《马克思恩格斯文集》**
- **《马克思恩格斯全集》（第一版）**
- **《党的文献》及其前身刊物（1982—2007年）**

## 一、资源特色

本项目优先保存直接提取自正式出版数字载体的 PDF 文献，而非普通的纸质书扫描件或重新排版版本。

### 1. 官方原版排版

前三套经典著作均提取自**人民出版社正式出版的数字 U 盘版**，保留了原出版物的版式设计与排版风格。

- 忠实保留原书的版面布局与文字排版
- 无须重新排版，和原书面貌基本完全一致
- 版面规范、清晰美观，阅读体验非常良好

### 2. 舒适的阅读体验

相较于常见的扫描版 PDF，本项目收录的电子文献具有明显的阅读优势：

- **排版舒适**：采用正式出版物的专业排版，适合长时间阅读
- **文字清晰**：电子文本显示清晰，放大后依然具有良好的可读性
- **内容完整**：保留原著内容及出版物的完整结构
- **全文可检索**：支持 PDF 内文字搜索，便于快速定位关键词、人物及历史事件
- **文本可编辑**：支持文字选择、复制、提取，可任意编辑和整理

这些特点使本项目的 PDF 不仅适合日常阅读，也特别适合学术引用、文献整理、文本研究和数字人文研究。
